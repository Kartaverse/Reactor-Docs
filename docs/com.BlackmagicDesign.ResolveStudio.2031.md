## Description
<h2>Resolve Studio 20.3.1</h2>
<p>For your convenience, here are download links to Resolve Standalone full version releases that are available on the Blackmagic Design support page.</p>
<h2>What's new</h2>
<p>The following features have been added or updated.</p>
<ul>
<li>Addressed a crash in the metadata view with some custom fields.</li>
<li>Addressed an issue with stereoscopic 3D video monitoring output.</li>
<li>Addressed an issue with embedding HDR10 metadata.</li>
<li>Addressed client preview with viewer overlays on remote monitor.</li>
<li>Addressed effects search issue for Chinese, Japanese and Korean.</li>
<li>Addressed issue using embedded Dolby Vision metadata in IMF.</li>
<li>Addressed incorrect Fusion viewer overlay positions after transforms.</li>
<li>Addressed MultiMerge masking issue with concatenated transforms.</li>
<li>General performance and stability improvements.</li>
</ul>
