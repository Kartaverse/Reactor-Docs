# BMD Resolve Free 21.0.0 Public Beta 1

Bin/BMD

## Description
<h2>Resolve Free 21.0.0 Public Beta 1</h2>
<p>For your convenience, here are download links to Resolve Standalone full version releases that are available on the Blackmagic Design support page.</p>
<h2>What's new</h2>
<p>The following features have been added or updated.</p>

Photo Page
<ul>
<li>New photo image editing now fully integrated within DaVinci Resolve.</li>
<li>Image library with tagging, favorites, ratings and album collections.</li>
<li>Albums let you build, manage and tweak photos at source resolution.</li>
<li>Native RAW support for major camera formats.</li>
<li>Direct image capture via Sony or Canon tethered cameras.</li>
<li>Import media from Apple Photos on macOS.</li>
<li>Import Lightroom Catalog files into the media pool.</li>
<li>Use Resolve multi-user collaboration and Blackmagic Cloud syncing.</li>
<li>Support for DaVinci color control toolset and grading panels.</li>
<li>Use all of Resolve's native AI toolset including AI IntelliSearch.</li>
<li>Looks, LUTs, ResolveFX and OpenFX for your images.</li>
<li>GPU accelerated batch exports and conversions.</li>
</ul>

AI Tools
<ul>
<li>AI IntelliSearch lets you easily search for people or objects.</li>
<li>AI Speech Generator transforms written text to spoken voice.</li>
<li>AI CineFocus allows refocus with realistic bokeh and lens effects.</li>
<li>AI Face Age Transformer lets you age or de-age a face.</li>
<li>AI Face Reshaper for flexible reshape and resize of facial features.</li>
<li>AI Blemish Removal to repair facial and skin blemishes.</li>
<li>AI SlateFinder automatically detects slates and marks position.</li>
<li>AI SlateID to read slate and populate clip metadata.</li>
<li>AI UltraSharpen for high fidelity sharpening of moving images.</li>
<li>AI Motion Deblur enables removal of common motion blur artifacts.</li>
<li>Improved AI UltraNR quality for UHD and higher timelines.</li>
</ul>

Cut and Edit Page
<ul>
<li>Keyframing provides powerful retime controls with 4-point bezier.</li>
<li>Keyframe and add curves for multiple selected clips.</li>
<li>Keyframing ease options, loop, ping pong, reverse and stretch.</li>
<li>Keyframe Fusion effects, generators and text along with edit effects.</li>
<li>Subframe support for keyframing and markers.</li>
<li>Native support for OGraf HTML graphics.</li>
<li>Native support for Lottie animations.</li>
<li>Resolve FX Picture in Picture effect.</li>
<li>Font browser window for text and subtitle elements.</li>
<li>Preview fonts during font selection as a preference.</li>
<li>Spell checking for all text elements.</li>
<li>Emoji and color fonts for Text+ and MultiText.</li>
<li>Multicam angle previews in clean feed and video outputs.</li>
<li>Multicams can include all audio tracks for each angle.</li>
<li>Multicams can use full clip extents on creation and during sync.</li>
<li>Replay control to limit view to the last 5 minutes of recorded media.</li>
<li>Replay editor allows timeline selection from search dial.</li>
<li>Replay now allows independent start and end stingers.</li>
<li>Replay title palette allows up to 6 favorite titles.</li>
<li>Mono audio now plays on left and right channels of stereo tracks.</li>
<li>Improved waveforms, markers and fades for short edit tracks.</li>
<li>Source timelines support auto track selectors.</li>
<li>DRT timeline import supports link and conform options.</li>
<li>Compare timelines with timeline backup snapshots.</li>
<li>Subtitle inspector now supports search and replace.</li>
<li>Edit page lets you show or hide tracks from the index.</li>
<li>Support for editing EDL clip name in the edit index.</li>
<li>Affinity .af file support with group and individual layer control.</li>
<li>IntelliScript supports Final Draft or plain text screenplay imports.</li>
<li>Faster audio transcription and improved subtitle word timing.</li>
<li>Edit page timecode options for frames, subframes or audio samples.</li>
<li>Duration timecode option to show duration for clip selection.</li>
<li>Improved timeline view options with presets and clip name option.</li>
<li>View remote color versions in the source viewer.</li>
<li>Local color grade versions use remote grades on new clip creation.</li>
<li>Up to 2x faster AI Speed Warp Metal option on macOS.</li>
<li>Timeline menu action to select transitions in the cut and edit page.</li>
<li>Paste and remove attributes for clip color, markers and flags.</li>
<li>Paste and remove attributes to retain image position under crop.</li>
<li>Switch audio channels for multi-clip selections via the context menu.</li>
<li>Edit page source tape supports stereoscopic 3D clips.</li>
<li>Edit page source tape includes multicam clips.</li>
<li>Match frame finds source media for nested clips and multicams.</li>
<li>Resolve FX Video Collage with separate tile fill and border controls.</li>
<li>Subtitle support for fade in and out.</li>
</ul>

Media Pool and Metadata
<ul>
<li>Support for tabbed layouts.</li>
<li>Thumbnail, list and metadata views can be set for each bin.</li>
<li>Star rating support for clips.</li>
<li>Cut page supports smart bin views.</li>
<li>Export media bin thumbnails as a PDF.</li>
<li>Automatic smart bin and clip filter for offline clips.</li>
<li>Custom metadata for smart bins, filters, data burn and naming tags.</li>
<li>Customize your project poster frames.</li>
<li>Show input colorspace and gamma in metadata view.</li>
<li>Transcription column support in list view.</li>
<li>Custom keyboard shortcuts to set thumbnail, list or metadata views.</li>
<li>Ability to reset audio clip attributes to the original configuration.</li>
</ul>

Color Page
<ul>
<li>MultiMaster trim pass to grade single timeline to many deliverables.</li>
<li>Render Magic Mask in place as an external matte.</li>
<li>Clip groups now support grade versions.</li>
<li>Node graphs can now be viewed as a layer list.</li>
<li>Node stacks now support up to 8 layers.</li>
<li>Film Look Creator adds Aurora preset and contrast roll-off controls.</li>
<li>Film Look Creator softness controls support for film gate.</li>
<li>Shared node support for stereoscopic 3D clips.</li>
<li>Customizable HDR and nit scopes ranges.</li>
<li>Multiple HDR Vivid improvements, including mini panel controls.</li>
<li>ACES AMF improvements, with transform name and custom folders.</li>
<li>Reset Dolby Vision and HDR analysis from the option menu.</li>
<li>Adobe RGB colorspace and gamma support.</li>
<li>OpenFX 1.5 color management APIs for colorspace aware effects.</li>
<li>Advanced panel controls for 2.39 and 2.4 safe area aspect ratios.</li>
<li>Multi-user projects can bypass color management on the color page.</li>
<li>Motion Blur option for Metal on macOS.</li>
<li>Pasting tracking data between power windows retains original shape.</li>
</ul>

Immersive and VR Workflows
<ul>
<li>Apple Immersive workflows now support foveated rendering.</li>
<li>Initial VR180 and VR360 standard immersive workflow support.</li>
<li>View VR180 and VR360 source clips as immersive or viewport.</li>
<li>Mix and match VR180 and VR360 in immersive timelines.</li>
<li>Standard immersive timelines support immersive transform controls.</li>
<li>VR180 and VR360 deliver presets for Meta Quest and YouTube.</li>
<li>LatLong patcher allows customizable field of view.</li>
<li>Fusion adds Panomap immersive rotation and ILPD retargeting.</li>
</ul>

Fairlight Page
<ul>
<li>Folder tracks allow a group of tracks to be folded down or expanded.</li>
<li>Go to mouse pointer support using the C key.</li>
</ul>

Fusion Page
<ul>
<li>Support for Krokodove motion graphics effects.</li>
<li>Over 100 new motion graphics effects and tools.</li>
<li>New Macro Editor with inspector view and publishing to edit effects.</li>
<li>Fusion animation can be creatively driven by Fairlight audio.</li>
<li>Native support for OGraf HTML graphics.</li>
<li>Native support for Lottie animations.</li>
<li>Text+ and MultiText support spell checking.</li>
<li>Font improvements include emoji, color fonts and more.</li>
<li>Improved MultiText for position, pivot, alignment and CSV import.</li>
<li>Support for USD SDK 25.11 with Hydra 2.0 API for Storm renderer.</li>
<li>USD support for 3D matte objects and textures.</li>
<li>Support for USD Texture Projector and Catcher.</li>
<li>Global in-out controls for USD Loader.</li>
<li>3D Renderer support for Cryptomatte.</li>
<li>Native support for creating Relief Maps.</li>
<li>Change inspector properties for multi-tool selections.</li>
<li>Change common inspector values in all selected multi-tool layers.</li>
<li>Multilayer support for stereoscopic 3D clips and deep images.</li>
<li>Color correction for deep images in Fusion.</li>
<li>User defined metadata variables in paths, expressions and scripts.</li>
<li>Lens Distort offers checkerboard calibration and GPU acceleration.</li>
<li>Vector channel support in multilayer workflows.</li>
<li>Guides and rulers persistence, presets and improved snapping.</li>
<li>MediaIn nodes show clip name.</li>
<li>Open keyframes and spline as a new window.</li>
<li>Up to 2x faster Relight tool.</li>
<li>Up to 6x faster Depth Map tool.</li>
<li>Support for remote monitoring of Fusion previews.</li>
</ul>

Codecs and I/O
<ul>
<li>Enhanced MXF growing file support for broadcast workflows.</li>
<li>MXF OP1A support for MPEG2 bitrate and other encode options.</li>
<li>Canon CR3 RAW decode support.</li>
<li>Fujifilm RAF RAW decode support.</li>
<li>Apple ProRAW decode support.</li>
<li>Support for compressed ARW from Sony A7V and newer cameras.</li>
<li>Improved Nikon NEF RAW decode support.</li>
<li>HDR decode support for HEIC, JPEG, PNG and TIFF images.</li>
<li>HEIC encode support on macOS and Windows.</li>
<li>HDR encode support for HEIC, JPEG, PNG and TIFF images.</li>
<li>Improved EXIF metadata support for stills formats.</li>
<li>HDR Vivid supplementary IMF ISXD package support.</li>
<li>MainConcept H.265 and MV-HEVC 4:2:0 and 4:2:2 encode support.</li>
<li>Intel QuickSync H.264 10-bit 4:2:0 and 4:2:2 decode support.</li>
<li>Intel QuickSync AVC Intra decode support.</li>
<li>Intel QuickSync AV1 4:4:4 decode and encode support.</li>
<li>MV-HEVC decode support on Nvidia systems.</li>
<li>Encode support for multi-output audio only ambisonic formats.</li>
<li>Per render job option to override RCM or ACES outputs.</li>
</ul>

General Improvements
<ul>
<li>Background renders, quick exports and proxy generation.</li>
<li>Background analysis for transcription and audio classification.</li>
<li>Powerful, expanded and flexible data burn-in window.</li>
<li>Preferences and project settings can now be searched.</li>
<li>Multi-user projects support dynamic project switching.</li>
<li>Up to 3x faster file sync performance to Blackmagic Cloud.</li>
<li>General performance and stability improvements.</li>
</ul>
