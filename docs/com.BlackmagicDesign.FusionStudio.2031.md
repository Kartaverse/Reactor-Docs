## Description
<h2>Fusion Studio 20.3.1</h2>
<p>For your convenience, here are download links to Fusion Standalone full version releases that are available on the Blackmagic Design support page.</p>
<h2>What's new</h2>
<p>The following features have been added or updated.</p>
<ul>
<li>Address issue with swizzler RGB/A color setting.</li>
<li>Address incorrect viewer overlay positions after transforms.</li>
<li>Address issue with keyframe indicators and hidden controls.</li>
<li>Address MultiMerge masking issue with concatenated transforms.</li>
<li>Address issue with importing some PSDs.</li>
<li>Addressed issue with some OpenEXRs and Cryptomatte.</li>
<li>Addressed issue with size ignoring pivot in Duplicate tools.</li>
<li>General performance and stability improvements.</li>
</ul>
