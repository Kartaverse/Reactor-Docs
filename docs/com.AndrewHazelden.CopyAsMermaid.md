## Description
<h2>Copy As Mermaid</h2>
<p>The Copy As Mermaid script lets you copy a selection of Fusion nodes to your clipboard, formatted as a <b>Mermaid flowchart</b>. Mermaid is an open-source graphing format that allows you to create vector charts that can be saved to a markdown format and rendered inline in a webpage.</p>

<p>https://mermaid.ai/open-source/syntax/flowchart.html</p>

<p>It is possible to customize the script so it will output a Mermaid flowchart as either markdown, or BBCode format for use on the WSL forums. You can also change the flowchart build direction from TB (Top Bottom) to LR (Left Right).</p>

<p>The included Config file maps adds the action to Fusion's Edit menu.</p>
