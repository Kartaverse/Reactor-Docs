## Description
<h2>Resolve Free 20.3.2</h2>
<p>For your convenience, here are download links to Resolve Standalone full version releases that are available on the Blackmagic Design support page.</p>
<h2>What's new</h2>
<p>The following features have been added or updated.</p>
<ul>
<li>Preferences option to enable dynamic trim for trim editor in edit.</li>
<li>More consistent kerning for subtitles.</li>
<li>Magic mask cache is now retained when pasting node attributes.</li>
<li>Improved render speeds for side-by-side stereoscopic 3D renders.</li>
<li>Up to 2.5x faster SuperScale Enhanced with Apple Neural Engine.</li>
<li>Progressive renders for interlaced timelines with same frame rate.</li>
<li>Addressed issue with lens correction of vertical clips.</li>
<li>Addressed incorrect ILPD used with disabled clip on higher tracks.</li>
<li>Addressed incorrect aivu when rendering marked timeline ranges.</li>
<li>Addressed incorrect ImmersivePatcher behavior with proxy media.</li>
<li>Addressed timecode issue for proxies from stereoscopic 3D EXRs.</li>
<li>Addressed issue localizing media pool column headers.</li>
<li>Addressed slow media management start up for larger projects.</li>
<li>Addressed ProRes RAW decode issue when using ACES.</li>
<li>Addressed issue with editing effects on a locked node stack layer.</li>
<li>Analog Damage disabling CRT scan no longer disables restless foot.</li>
<li>Addressed potential flicker in face refinement eyebag removal.</li>
<li>Addressed retention of MaxCLL from XML when exporting IMF.</li>
<li>Addressed issues with Dolby Atmos external renderers.</li>
<li>Addressed ADC reverb delay compensation issue in some projects.</li>
<li>Addressed incorrect pass through behavior for Sony XAVC renders.</li>
<li>Addressed issue decoding some Sony ARW clips.</li>
<li>Addressed incorrect render size estimates for some MXF clips.</li>
<li>Support for Fujifilm F-Gamut C colorspace and F-Log2 C gamma.</li>
<li>Support for Dolby headphone personalization of binaural monitoring.</li>
<li>General performance and stability improvements.</li>
</ul>
