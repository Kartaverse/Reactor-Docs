## Description
<p>Mug Advanced Halftone is a halftone generation plugin for DaVinci Resolve and Fusion.</p>

<p>It allows you to create vintage print effects, pop art styles, and retro PC graphics.</p>

<p><b>Main Features:</b></p>
<ul>
<li>Various grid layouts including hexagonal patterns</li>
<li>Customizable dot shapes (Circle, Square, Diamond, Line, Crosshatch)</li>
<li>Organic jitter for a more natural look</li>
<li>RGB Shift and color palette limitations for authentic retro aesthetics</li>
</ul>

<h3>How to use on the Edit Page:</h3>
<ul>
<li>Open the Effects Library on the Edit page.</li>
<li>Navigate to <b>Toolbox &gt; Effects &gt; MugLab</b> and drag "MugAdvancedHalftone" onto your clip.</li>
<li>Adjust the parameters in the Inspector panel.</li>
</ul>

<h3>How to use in Fusion:</h3>
<ul>
<li>After installing via Reactor, restart DaVinci Resolve if the tool does not appear in your library.</li>
<li>Search for "Mug Advanced Halftone" in the Fusion tool menu (Shift+Space).</li>
<li>Connect your media to the input and adjust parameters in the Inspector.</li>
</ul>

<h3>Essential Notes:</h3>
<ul>
<li>Ensure you have the latest version of DaVinci Resolve for optimal performance.</li>
<li>GPU acceleration is supported; performance may vary depending on your hardware.</li>
<li>Commercial use is permitted under the MIT License (Copyright notice is not required for rendered video works).</li>
</ul>
